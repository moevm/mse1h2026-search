## Протокол встречи 
1. Безопасность и подготовка дампа базы данных
    - Обсуждалось открытие публичного доступа к дампу для преподавателей. Из-за большого объема (около 500 МБ в распакованном виде) и потенциальных рисков решено не загружать дамп в публичный репозиторий.
    - Принято решение создать специальный, урезанный дамп базы данных, который будет содержать только те таблицы и строки, которые необходимы для выполнения конкретных поисковых запросов приложения.
2. Развертывание через Docker Compose
    - Для удобства проверяющих файл Docker Compose будет обновлен: при старте контейнеров подготовленный дамп MySQL будет автоматически скачиваться и применяться (в случае, если база еще не инициализирована).
3. Конфигурация SQL-запросов
    - Принято решение вынести сырые SQL-запросы в конфигурационный файл для упрощения настройки и дальнейшей поддержки приложения.
