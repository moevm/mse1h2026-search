1. Демонстрация прототипа на Meilisearch
    - В ходе показа был обнаружен баг с отображением заглушки вместо даты публикации, который решено исправить.

    - Для развертывания выделен домен, настройка будет произведена с помощью Docker Compose.
3. Переиндексация данных

    - Утверждена частичная инкрементальная переиндексация (для обновленных и удаленных статей) с частотой раз в час.
4. Интеграция сторонних эмбеддингов
