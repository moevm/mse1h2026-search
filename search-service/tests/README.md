# Тесты для Search Service

В данной директории хранится инфраструктура автоматизированного тестирования проекта. На текущий момент здесь реализован модуль **тестов пользовательского интерфейса (UI)**, однако структура позволяет легко интегрировать сюда API-тесты и другие уровни проверок в будущем.
Управление зависимостями и виртуальным окружением осуществляется через **uv**. Основной тестовый фреймворк — **pytest**. Для имитации действий пользователя в браузере (UI-тестирование) применяется **Playwright**.

---

## Требования перед запуском

Перед тем как запускать тесты, убедитесь, что:
1. Основное приложение (frontend + backend) **запущено локально** (по умолчанию тесты стучатся на `http://localhost:6767`, этот параметр можно изменить в `tests/conftest.py`).
2. Вы находитесь в директории с тестами в терминале:
   
```bash
cd search-service/tests
```

## Установка и настройка

1. Установка зависимостей проекта:
```bash
uv sync
```
2. Установка бинарных файлов браузера Chromium для Playwright (требуется для модуля UI-тестов, выполняется однократно):
```bash
uv run playwright install --with-deps chromium
```

## Структура проекта

Архитектура тестов расположена в директории `tests/` и организована следующим образом:

*   `pytest.ini` — базовые настройки фреймворка pytest.
*   `conftest.py` — глобальные фикстуры и конфигурация инициализации браузера.
*   Директория `pages/` — включает базовый класс с универсальными ожиданиям(`base_page.py`) и класс страницы поиска с локаторами и методами взаимодействия (`search_page.py`).
*   Директория `ui_tests/` — модуль тестов пользовательского интерфейса.

## Запуск UI-тестов

1. Базовый запуск всех тестов:
```bash
uv run pytest ui_tests
```

2. Запуск с генерацией видеоотчета:
> Параметр --video=on активирует запись экрана. Параметр --slowmo=2000 добавляет искусственную паузу в 2000 миллисекунд перед каждым взаимодействием (клик, ввод текста). Все сгенерированные видеоотчеты сохраняются в директорию test-results/:
```bash
uv run pytest ui_tests/test_search_filters_complex.py --video=on --slowmo=2000
```

3. Визуальная отладка
>Параметр `--headed` принудительно открывает графическое окно браузера (отключает headless-режим), позволяя разработчику наблюдать за ходом выполнения теста. Параметр `--slowmo=2000` замедляет скрипт (ms), чтобы человеческий глаз успевал отслеживать автоматизированные клики и смену состояний интерфейса:
```bash
uv run pytest ui_tests/test_search_filters_complex.py --headed --slowmo=2000
```

4. Изолированный запуск конкретного теста:
```bash
uv run pytest ui_tests/test_search_filters_complex.py::test_filters_language_combinations_and_reset
```
